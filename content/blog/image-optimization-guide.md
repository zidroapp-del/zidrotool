# Image Optimization Guide: Resize, Compress and Convert Images for the Web

A fast image workflow starts with the dimensions users actually need. Sending a 5000-pixel image to a 600-pixel card wastes bandwidth even if the file is compressed.

## Resize first

Use [Image Resizer](/tools/image-resizer) to create a sensible display size. Keep the original source separately if you need it for future edits.

## Compress second

After resizing, use [Image Compressor](/tools/image-compressor) to reduce file size. Compare the visual result rather than selecting the strongest compression automatically.

## Convert when useful

[Image Converter](/tools/image-converter) can change formats. Web-friendly formats can reduce bytes, but choose based on the content and required compatibility.

## Preserve aspect ratio

Use the [Aspect Ratio Calculator](/tools/aspect-ratio-calculator) when creating exact dimensions. Preserving proportions prevents stretched images.

## Remove unnecessary metadata

Camera and editing software can embed metadata. [Image Metadata Remover](/tools/image-metadata-remover) can help remove metadata when it is not needed.

## Test the real page

Image optimization is not only about file size. Test loading behavior, layout stability, responsive images, and actual mobile performance.

## FAQ

### Should I resize before compression?

Usually yes. There is little value in compressing pixels that will never be displayed.

### Does every image need the same quality setting?

No. Photographs, screenshots, logos, and illustrations behave differently.

### Can image optimization improve SEO?

It can contribute to a faster, more usable page, but image optimization is only one part of SEO.
