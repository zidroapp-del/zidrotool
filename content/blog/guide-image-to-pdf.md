# Image to PDF: A Complete Guide for Scans, Receipts and Documents

Turning images into PDF is useful when a website, school, business, or government service requires one document instead of separate image files.

## Prepare the source images

Before converting, check that the images are readable and in the correct order. Crop unnecessary borders when they make text smaller.

For phone photos, keep the original resolution until after you have created the document.

## Page size and orientation

A document scan often works well on A4 or Letter. Photographs may look better when the page follows the image orientation.

Avoid stretching. Preserve the original aspect ratio and fit the image within the page.

## Convert in the browser

Use [Image to PDF](/tools/image-to-pdf) to turn images into PDF pages. After exporting, open the resulting file and check:

- page order
- orientation
- text readability
- margins
- file size

If the final PDF is too large, use [PDF Compressor](/tools/pdf-compressor).

## Privacy

Scanned documents can contain personal information. A local browser workflow is useful when you do not want to upload the files to a remote server.

## FAQ

### Can several images become one PDF?

Yes. Each image can become a page in a multi-page PDF.

### Does conversion improve image quality?

No. The PDF contains the source image; conversion cannot recover detail that is not present.

### Can I merge PDFs afterward?

Yes. Use [PDF Merger](/tools/pdf-merger) when you need to combine separate PDF documents.
