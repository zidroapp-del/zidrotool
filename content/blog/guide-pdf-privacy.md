# How to Handle Sensitive PDFs Safely in Your Browser

PDF files often contain contracts, invoices, identity documents, financial records, or private notes. Choosing how a tool processes those files matters.

## Local processing vs upload-based processing

A browser tool can sometimes perform operations locally using Web APIs and JavaScript libraries. In that model, the file is processed on your device.

Upload-based services send the document to a remote server for processing. That can be useful for heavy workloads, but it creates a different privacy and retention model.

Always check a tool's privacy policy before processing sensitive documents.

## Practical precautions

Before uploading any sensitive file to a service:

- check whether files are retained
- check whether processing is encrypted
- check whether files are deleted automatically
- avoid unnecessary personal information
- use a trusted network
- keep your browser updated

For local workflows, close the page when you are finished and remove temporary downloads if appropriate.

## FAQ

### Is local processing automatically private?

Local processing can reduce data transmission, but privacy also depends on the page, browser, extensions, analytics, and the rest of the application.

### Should I process an identity document online?

Use extra caution. If the operation can be done locally and you trust the application, that can reduce the need to upload the file.

### Does PDF encryption make a file completely safe?

No. Encryption protects data in specific circumstances, but passwords, sharing, device security, and metadata still matter.
